# Менеджер задач

Экран собран из компонентов библиотеки ALTA по макету «Программные блоки (POU)».

Превью: [Открыть экран](https://nastya-nikki.github.io/ALTA/Layouts/TaskManager/).  
Источник: [Design layouts, node 10342:833579](https://www.figma.com/design/rMHVuI6H3bD8Kb7h940cIl/?node-id=10342-833579).  
Статус: реализовано, ожидает проверки дизайнером.  
Макет прочитан 02.11.2026.

Подключены существующие HTML/CSS/JavaScript компонентов меню, дерева, ячеек, заголовков таблицы, разделителей и иконок. Список экземпляров, выбранных вариантов и исходных узлов находится в `components-used.json`. Реализации и общие ресурсы компонентов не изменены.

`index.html` содержит композицию экрана, `layout.css` — расположение и значения переменных конкретного макета, `layout.js` — локальное выделение строк, сворачивание ветвей, навигацию с клавиатуры и изменение ширины дерева. `assets/` содержит оригинальные ресурсы экземпляров Figma, для которых не найдено точного совпадения в библиотеке. Изображение макета не используется для отрисовки страницы.

Экран использует демонстрационные данные макета. Команды верхней панели не создают проекты и не отправляют данные во внешние системы. Цветовые значения макета заданы в области этой страницы, поскольку они отличаются от текущих значений библиотеки.
