# AltaIDE_SidebarDeviceSettingsFDILight

Источник: [AltaIDE/SidebarDeviceSettings/FDI/Light, node 185669:5904](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=185669-5904).

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `sidebar-device-settings-fdilight.css` — оформление из дизайн-контекста.
- `sidebar-device-settings-fdilight.js` — подтверждённые варианты.
- `assets/` — исходные идентификаторы и оригинальные ресурсы Figma.
- `../../tokens/altaide-composed.css` — проверенные токены и цепочки алиасов Figma.
- `../../assets/alta/shell.js` — общая логика локального примера.

Полные значения переменных, режимы и цепочки алиасов проверены в текущей Figma и сохранены в `../../tokens/figma-altaide-composed-variables.json`.

Показан фиксированный вид дерева из Figma. Переходы раскрытия групп не заданы; новые состояния не добавлены.
