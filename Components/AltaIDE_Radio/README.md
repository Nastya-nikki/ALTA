# AltaIDE_Radio

Переключатель выбора одного значения.

Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/Components/AltaIDE_Radio/preview.html)  
Источник: [AltaIDE/Radio, node 185163:8896](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=185163-8896).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `radio.css` — геометрия и привязки к токенам Figma.
- `radio.js` — подтверждённые конфигурации.
- `assets/figma-source.json` — свойства, измерения и вложенные компоненты.
- `assets/*.svg` — оригинальные SVG из Figma.
- `../../tokens/` и `../../assets/fonts/` — общие токены и шрифты.
- `../../assets/alta/controls.*` — общие механизмы управления.

В исходнике названия состояний зависят от Selected: Default/Hover для Off и Active/Hovered для On. Сохранены только существующие сочетания.
