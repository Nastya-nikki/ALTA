# AltaIDE_Dropdown

Поле выбора значения из списка.

Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/Components/AltaIDE_Dropdown/preview.html)  
Источник: [AltaIDE/Dropdown, node 185521:27721](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=185521-27721).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — пример компонента.
- `preview.html` — варианты, состояния и демонстрация по применимости.
- `dropdown.css` — стили вариантов из Figma.
- `dropdown.js` — точный перечень вариантов и подключение общей логики.
- `assets/figma-source.json` — свойства, измерения и ссылки на переменные Figma.
- `assets/*.svg` — оригинальные графические ресурсы Figma.
- `../../tokens/` — общие токены с режимами и алиасами.
- `../../assets/fonts/` — общие шрифты.
- `../../assets/alta/` — общая логика и оформление карточек.

Демонстрация работает с локальными данными. Действия, не описанные в Figma, являются технической демонстрацией; визуальные варианты взяты только из исходника.
