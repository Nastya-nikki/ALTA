# AltaCFC_Ports

Порт соединения узлов.

Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/Components/AltaCFC_Ports/preview.html)  
Источник: [AltaCFC/Ports, node 97:24](https://www.figma.com/design/mH9VH4Aa9UWukg9HWFvT8y/?node-id=97-24).  
Статус: реализовано, ожидает проверки дизайнером и завершения сверки переменных.  
Дизайн и варианты прочитаны 01.11.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `ports.css` — оформление по актуальной спецификации Figma.
- `ports.js` — существующие варианты и состояния.
- `assets/figma-source.json` — исходные идентификаторы, свойства и ограничения чтения.
- `../../tokens/alta-cfc.css` — значения из визуальной спецификации Figma.
- `../../assets/alta/cfc.js` — общая логика компонента и локального примера.

Лимит Figma MCP остановил полное чтение переменных, цепочек алиасов и режимов. В CSS использованы значения из полученной визуальной спецификации; они не выданы за проверенный каталог переменных.

У компонента сохранены 24 существующих вариантов. Редкие названия и повторяющиеся сочетания свойств сохранены по исходным node ID.

Интерактивный пример использует локальные демонстрационные данные. Выбор, редактирование и подключение портов — механизмы браузера; диаграмма и внешние данные не изменяются.
