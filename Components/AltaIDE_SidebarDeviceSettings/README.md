# AltaIDE_SidebarDeviceSettings

Боковая панель настроек устройства.

Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/Components/AltaIDE_SidebarDeviceSettings/preview.html)  
Источник: [AltaIDE/SidebarDeviceSettings, node 185669:5908](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=185669-5908).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 02.11.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `sidebar-device-settings.css` — оформление из дизайн-контекста.
- `sidebar-device-settings.js` — подтверждённые варианты.
- `assets/` — исходные идентификаторы и оригинальные ресурсы Figma.
- `../../tokens/altaide-composed.css` — проверенные токены и цепочки алиасов Figma.
- `../../assets/alta/shell.js` — общая логика локального примера.

Полные значения переменных, режимы и цепочки алиасов проверены в текущей Figma и сохранены в `../../tokens/figma-altaide-composed-variables.json`.

Структура строк и иконки сохранены из конкретных экземпляров Figma. Выбор и навигация работают локально; дополнительные ветви не создаются.
