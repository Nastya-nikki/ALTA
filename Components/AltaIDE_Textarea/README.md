# AltaIDE_Textarea

Поле для ввода многострочного текста.

Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/Components/AltaIDE_Textarea/preview.html)  
Источник: [AltaIDE/Textarea, node 185274:6084](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=185274-6084).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `textarea.css` — геометрия и привязки к токенам Figma.
- `textarea.js` — подтверждённые конфигурации.
- `assets/figma-source.json` — свойства, измерения и вложенные компоненты.
- `assets/*.svg` — оригинальные SVG из Figma.
- `../../tokens/` и `../../assets/fonts/` — общие токены и шрифты.
- `../../assets/alta/controls.*` — общие механизмы управления.

Ввод, изменение размера и переключение подтверждённых состояний реализованы как механизмы браузера; новые варианты в Figma не добавлялись.
