# AltaIDE_TooltipCodeEditor

Подсказка с одним или несколькими сообщениями.

Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/Components/AltaIDE_TooltipCodeEditor/preview.html)  
Источник: [Tooltip_CodeEditor, node 202318:2288](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=202318-2288).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `tooltip-code-editor.css` — геометрия и привязки к токенам Figma.
- `tooltip-code-editor.js` — подтверждённые конфигурации.
- `assets/figma-source.json` — свойства, измерения и вложенные компоненты.
- `assets/*.svg` — оригинальные SVG из Figma.
- `../../tokens/` и `../../assets/fonts/` — общие токены и шрифты.
- `../../assets/alta/controls.*` — общие механизмы управления.

Вариант SRC в Figma не имеет фоновой панели; это отличие сохранено.
