## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `lt.css` — оформление по актуальной спецификации Figma.
- `lt.js` — существующие варианты и состояния.
- `assets/figma-source.json` — исходные идентификаторы, свойства и проверенные привязки.
- `assets/*.svg` — оригинальные SVG Figma.
- `../../tokens/alta-cfc.css` — переменные и цепочки алиасов Figma.
- `../../assets/alta/cfc.js` — общая логика компонента и локального примера.

Проверенный экспорт переменных и доступных режимов сохранён в `../../tokens/figma-alta-cfc-variables.json`. Собственная коллекция AltaCFC содержит режим Mode 1; импортированные режимы сохранены в данных без добавления новых тем в превью.

Интерактивный пример использует локальные демонстрационные данные. Выбор, редактирование и подключение портов — механизмы браузера; диаграмма и внешние данные не изменяются.
