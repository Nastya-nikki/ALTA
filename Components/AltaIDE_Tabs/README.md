# AltaIDE_Tabs

Группа вкладок.

Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/Components/AltaIDE_Tabs/preview.html)  
Источник: [AltaIDE/Tabs, node 185583:24833](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=185583-24833).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 31.10.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `tabs.css` — измерения и привязки к токенам Figma.
- `tabs.js` — подтверждённые конфигурации.
- `assets/figma-source.json` — исходные свойства, размеры и зависимости.
- `assets/*.svg` — оригинальные ресурсы Figma.
- `../../assets/alta/navigation.*` — общая логика и механика браузера.
- `../../tokens/` и `../../assets/fonts/` — общие токены и шрифты.
- `../AltaIDE_Tab/` — вложенный компонент.

Необязательная вкладка Home использует экземпляр удалённой библиотеки AltaIDE/Tab. Её измерения и оформление перенесены из самого экземпляра в Tabs; отдельный исходный набор по его ID недоступен.
