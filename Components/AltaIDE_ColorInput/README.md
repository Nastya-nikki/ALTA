# AltaIDE_ColorInput

Поле ввода шестнадцатеричного значения цвета.

Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/Components/AltaIDE_ColorInput/preview.html)  
Источник: [AltaIDE/ColorInput, node 203857:34249](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=203857-34249).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка вариантов и демонстрация.
- `color-input.css` — геометрия и токены из Figma.
- `color-input.js` — подтверждённые конфигурации.
- `assets/figma-source.json` — свойства и измерения.
- `../../tokens/` — общие токены и режимы.
- `../../assets/fonts/` — исходные шрифты.
- `../../assets/alta/widgets.*` — общая техническая логика элементов выбора.

Изменение данных в интерактивном примере — демонстрационный сценарий. Исходные значения и варианты в таблицах сохранены.

В Figma исходное значение `3D414B` и цвет образца `#5684DD` различаются. Начальный вид сохранён; в демонстрации образец обновляется после ввода корректного HEX. Проверка формата HEX — техническое поведение примера.
