# AltaIDE_ButtonPrimary

Кнопка основного действия: создать, сохранить или подтвердить.

Превью: [Открыть демонстрацию Primary Button](https://nastya-nikki.github.io/ALTA/Components/AltaIDE_ButtonPrimary/preview.html)  
Источник: [AltaIDE/ButtonPrimary, node 185100:882](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=185100-882).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 30.10.2026.

## Файлы

- `index.html` — минимальный пример реальной кнопки.
- `preview.html` — согласованная карточка: варианты, состояния в одну строку, интерактивный пример в конце.
- `button.css` — единые стили компонента и всех его вариантов.
- `button.js` — блокировка повторного запуска при загрузке, синхронизация доступности и состояния иконок.
- `assets/icons/` — оригинальные SVG из Figma: Dummy и Spiner, в размерах 20 и 16 px. SVG не перерисованы.
- `../../tokens/tokens.css` — общие переменные Figma и значения текстовых стилей.
- `../../tokens/figma-button-primary.json` — исходные ID, алиасы, режимы, привязки и измерения всех 40 вариантов.
- `../../assets/fonts/` — общий Rubik Regular и лицензия OFL.

Открыть `preview.html` можно локально или на статическом HTTP-сервере. Внешние библиотеки, сборка и интернет не требуются.
