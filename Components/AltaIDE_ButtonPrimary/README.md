# AltaIDE_ButtonPrimary

Кнопка основного действия: создать, сохранить или подтвердить.

Источник: [AltaIDE/ButtonPrimary, node 185100:882](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=185100-882). Дизайн, переменные и варианты прочитаны 30.10.2026. Статус: реализовано, ожидает проверки дизайнером.

## Файлы

- `index.html` — минимальный пример реальной кнопки.
- `preview.html` — согласованная карточка: варианты, состояния в одну строку, интерактивный пример в конце.
- `button.css` — единые стили компонента и всех его вариантов.
- `button.js` — блокировка повторного запуска при загрузке, синхронизация доступности и состояния иконок.
- `assets/icons/` — оригинальные SVG из Figma: Dummy и Spiner, в размерах 20 и 16 px. SVG не перерисованы.
- `../../tokens/tokens.css` — общие переменные Figma и значения текстовых стилей.
- `../../tokens/figma-button-primary.json` — исходные ID, алиасы, режимы, привязки и измерения всех 40 вариантов.
- `../../assets/fonts/` — общий Rubik Regular и лицензия OFL.

Открыть `preview.html` можно локально или на статическом HTTP-сервере. Внешние библиотеки, сборка и интернет не требуются.

## Подключение

Подключите `../../assets/fonts/fonts.css`, затем `../../tokens/tokens.css`, `./button.css` и `./button.js`. Все пути здесь относительно папки компонента. Разметку с локальными SVG скопируйте из `index.html`; при переносе на другую страницу скорректируйте пути к ресурсам.

Класс: `alta-button`. Атрибуты повторяют значения Figma:

| Свойство | Значения |
| --- | --- |
| `data-size` | `Large`, `Medium` |
| `data-icon` | `Without`, `Left`, `Right`, `OnlyIcon` |
| `data-state` | `Default`, `Hover`, `Pressed`, `Loading`, `Disabled` |

Всего 40 сочетаний. Для `Disabled` необходим также нативный атрибут `disabled`. У `OnlyIcon` необходимо доступное имя через `aria-label` или `aria-labelledby`. `data-static` используется только для зафиксированных примеров в карточке, с `tabindex="-1"`.

При реальном взаимодействии Hover и Pressed работают автоматически. Отдельного варианта Focus в Figma нет: он не добавлен в галерею. Браузерный индикатор фокуса сохранён для управления клавиатурой.

```js
AltaButtonPrimary.setLoading(button, true);
// После завершения действия:
AltaButtonPrimary.setLoading(button, false);
```

Во время Loading текст остаётся видимым рядом со спиннером, как в Figma. Для `Without` спиннер добавляется слева; для `Right` располагается справа. У `OnlyIcon` виден только спиннер. Клики, программный `.click()`, Enter и Space не запускают действие повторно во время загрузки.

Демонстрационный таймер находится исключительно в `preview.html`. Компонент не создаёт проекты и не отправляет данные.

## Соответствие Figma

| Источник | CSS |
| --- | --- |
| `Buttons/hPadding` | `--buttons-hpadding` |
| `Buttons/Primary/vPadding` | `--buttons-primary-vpadding` |
| `Buttons/BetweenPadding` | `--buttons-betweenpadding` |
| `Buttons/Radius` | `--buttons-radius` |
| `Buttons/Primary/Background/{State}` | `--buttons-primary-background-{state}` |
| `Buttons/Primary/Content/{State}` | `--buttons-primary-content-{state}` |
| `AltaIDE/Body/Regular` | Rubik 400, 14/20 px, letter spacing 0 |
| `AltaIDE/Footnote/Regular` | Rubik 400, 12/16 px, letter spacing 0 |

Режимы коллекции Components: **Dark** (по умолчанию) и **Light**. Режим задаётся `data-theme="dark"` / `data-theme="light"` на странице или контейнере. Сохранены алиасы к коллекциям Source и Color; полный граф находится в JSON. В Light исходные формы иконок окрашиваются токеном содержимого через альфа-маски неизменённых SVG; встроенные данные масок обеспечивают работу через `file://`.

Непривязанные к переменным геометрические значения из Figma также вынесены в общую таблицу: размер иконки Large — 20 px, Medium — 16 px; высота исключения ниже — 26 px. Они помечены как измерения, а не выдуманные имена токенов Figma.

Особенности исходника сохранены:

- Large: высота 28 px; Medium: 24 px.
- Только иконка: ширина 44 px / 40 px. Кнопка не превращена в квадрат.
- Medium + Disabled + Right (`185100:870`): высота **26 px**, как в Figma.
- Large + Default + Without (`185100:854`): фон напрямую связан с **Dark/Blue/7**, поэтому не переключается на Light/Blue/9. Остальные Default-варианты используют семантический токен.
- Loading + Without увеличивается на ширину спиннера и зазора, как в исходном наборе.

## Проверка

Проверены все 40 сочетаний: размеры, фон, типографика, отступы, скругление и загрузка оригинальных SVG. Проверены нажатие, Loading, блокировка повторного запуска, сброс таймера, Enter/Space и узкий экран 390 px. Карточка использует те же `button.css`, `button.js` и ресурсы, что и `index.html`.

Полная проверка дизайнером ещё не выполнена. Задержка демонстрационного действия — 1,5 секунды; это сценарий предпросмотра, а не свойство Figma. В Figma экспортирован статический рисунок Spiner, поэтому собственная анимация вращения не добавлена.
