# AltaIDE_ModalLinkedProgram

Окно выбора программы для привязки.

Превью: [Открыть демонстрацию](https://nastya-nikki.github.io/ALTA/Components/AltaIDE_ModalLinkedProgram/preview.html)  
Источник: [AltaIDE/Modal_LinkedProgram, node 190191:3256](https://www.figma.com/design/axdKFZbeqNIfskP18KDs32/?node-id=190191-3256).  
Статус: реализовано, ожидает проверки дизайнером.  
Дизайн, переменные и варианты прочитаны 02.11.2026.

## Файлы

- `index.html` — отдельный пример.
- `preview.html` — карточка компонента.
- `modal-linked-program.css` — оформление из дизайн-контекста.
- `modal-linked-program.js` — подтверждённые варианты.
- `assets/` — исходные идентификаторы и оригинальные ресурсы Figma.
- `../../tokens/altaide-composed.css` — проверенные токены и цепочки алиасов Figma.
- `../../assets/alta/shell.js` — общая логика локального примера.

Полные значения переменных, режимы и цепочки алиасов проверены в текущей Figma и сохранены в `../../tokens/figma-altaide-composed-variables.json`.

Подтверждение и отмена используют демонстрационные данные без внешних изменений.
